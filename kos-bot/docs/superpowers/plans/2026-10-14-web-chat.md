# Website Chat, Renter Login and Dashboard Data — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Run the kos assistant in a chat window on the website (Claude API, no WhatsApp needed), let renters log in, run the whole sign-up flow with simulated payments, and manage all property data and photos from the owner dashboard.

**Architecture:** One shared assistant core. Tools stop sending WhatsApp messages and instead return *actions* (link buttons); a shared `handleInbound` pipeline (rate limits → injection filter → Claude → output guard → save) serves both the new web channel (`/api/chat` + a React widget) and the existing WhatsApp webhook. WhatsApp, Xendit and email become optional feature groups; without Xendit in development, a built-in fake payment page calls the same `recordPayment` function the Xendit webhook uses.

**Tech Stack:** Next.js 15 (App Router, route handlers), React 19, TypeScript strict, Prisma 6 + PostgreSQL, `@anthropic-ai/sdk` 0.129.0 with `claude-haiku-5-5`, zod 3, `sharp` 0.34.3, `vitest` 3.2.4.

**Spec:** `docs/superpowers/specs/2026-10-14-web-chat-design.md`

All paths below are relative to `kos-bot/`. Run every command from `kos-bot/`. The git repository root is the parent folder, so `git add` paths are written relative to `kos-bot/` and work from there.

Postgres binaries on this machine: `export PATH=/Applications/Postgres.app/Contents/Versions/latest/bin:$PATH`.

## Global Constraints

- Node >= 20.11, Next 15, Prisma 6, TypeScript `strict`. `npm run typecheck` must pass at the end of every task.
- New dependencies allowed: `vitest@3.2.4` (dev), `sharp@0.34.3`. Upgrade `@anthropic-ai/sdk` to exactly `0.129.0`. Nothing else.
- Default model: `claude-haiku-5-5`, `output_config.effort: "low"`, thinking left at its default (adaptive). No `temperature`/`top_p`/`top_k`, no assistant prefill, no forced `tool_choice`.
- Money is integer Rupiah. Never floats.
- Every visitor-facing string is casual-polite Bahasa Indonesia ("kak").
- Full KTP numbers and phone numbers never appear in logs, chat replies, or dashboard transcripts. Masked forms only.
- Every state-changing route checks the right session (owner or renter where applicable) **and** `sameOrigin(req)`; POSTs without an `Origin` header are rejected.
- Cookies: `kos_chat` (anonymous web chat id, 30 days), `kos_renter` (renter session, 7 days, carries `sessionVersion`), `kos_owner` (existing). All httpOnly, `SameSite=Lax`, `Secure` in production, signed with `SESSION_SECRET`.
- Chat message max 600 characters. Prospect chat retention 24 hours after last message; renter chat 90 days.
- Passwords: min 10 characters, scrypt `N=16384, r=8, p=1`, 16-byte salt, 64-byte key, stored `scrypt$<salt hex>$<hash hex>`. Lockout after 5 failures per phone or per IP in 15 minutes.
- Photos: JPG/PNG/WEBP, max 8 MB, magic-byte checked, re-encoded to WEBP, longest side 1600 px, all metadata stripped, stored under `photos/`.
- Fake payments only when Xendit is not configured **and** `NODE_ENV !== "production"`; production refuses to start without Xendit.

## Review Focus

1. **A renter whose lease has ended but still holds a valid login cookie** must get the prospect experience — no renter tools, no account data. Pinned in Task 10 (`resolveWebContext` test with an ENDED lease).
2. **A password reset (setup link) must log the renter out everywhere**: an old `kos_renter` cookie stops working once `sessionVersion` changes. Pinned in Task 10 (`renterFromCookie`) and Task 11 (`consumePasswordSetup`).
3. **After logging out on a shared browser, the chat must not show the renter's conversation** — only the anonymous one. Pinned in Task 10 (`findWebContactId` test).
4. **The owner changes a price or deposit while an applicant has the contract open**: the applicant must not sign text different from what they read. Pinned in Task 12 (contract hash check on signing + `contractHash` unit test).
5. **An uploaded "photo" that is really a renamed PDF, or a huge image**: rejected without crashing, nothing stored. Pinned in Task 14 (`processPhoto` tests).

Also guarded (with tests) inside their tasks: the 24-hour purge of an anonymous visitor who already signed (Task 6), and `javascript:` map links (Task 13).

```ts
import { env, type Env } from "@/env";

/**
 * Optional integrations. Each is on only when every value in its group is set,
 * so a half-filled .env never produces half-working behaviour.
 */
export function whatsappEnabled(e: Env = env()): boolean {
  return [
    e.WA_PHONE_NUMBER_ID,
    e.WA_ACCESS_TOKEN,
    e.WA_APP_SECRET,
    e.WA_VERIFY_TOKEN,
    e.WA_BOT_PHONE_E164,
    e.OWNER_PHONE_E164,
  ].every(Boolean);
}

export function paymentsLive(e: Env = env()): boolean {
  return Boolean(e.XENDIT_SECRET_KEY && e.XENDIT_WEBHOOK_TOKEN);
}

export function emailEnabled(e: Env = env()): boolean {
  return Boolean(e.RESEND_API_KEY);
}

/** The built-in "Simulasikan bayar" page exists only here. Never in production. */
export function fakePaymentsAllowed(e: Env = env(), nodeEnv = process.env.NODE_ENV): boolean {
  return !paymentsLive(e) && nodeEnv !== "production";
}

export function assertProductionReady(e: Env = env(), nodeEnv = process.env.NODE_ENV): void {
  if (nodeEnv === "production" && !paymentsLive(e)) {
    throw new Error(
      "Production needs XENDIT_SECRET_KEY and XENDIT_WEBHOOK_TOKEN. Fake payments are development-only."
    );
  }
}
```

```ts
/**
 * Signed, expiring cookie value: "<payload>.<expiry ms>.<hmac>".
 * The payload must not contain "." (ids and "id:version" pairs never do).
 */
export function signSession(payload: string, ttlMs: number): string {
  if (payload.includes(".")) throw new Error("Signed payload must not contain '.'");
  const exp = Date.now() + ttlMs;
  const body = `${payload}.${exp}`;
  const mac = crypto.createHmac("sha256", env().SESSION_SECRET).update(body).digest("hex");
  return `${body}.${mac}`;
}

/** The payload of a value made by signSession, or null if tampered or expired. */
export function readSigned(value: string | undefined): string | null {
  if (!value) return null;
  const parts = value.split(".");
  if (parts.length !== 3) return null;
  const [payload, exp, mac] = parts;
  const expected = crypto.createHmac("sha256", env().SESSION_SECRET).update(`${payload}.${exp}`).digest("hex");
  if (!safeEqual(mac, expected)) return null;
  if (!(Number(exp) > Date.now())) return null;
  return payload;
}

export function verifySession(cookie: string | undefined): boolean {
  return readSigned(cookie) !== null;
}
```

```ts
import crypto from "node:crypto";

const KEY_LENGTH = 64;
const SCRYPT = { N: 16_384, r: 8, p: 1, maxmem: 64 * 1024 * 1024 };

export const PASSWORD_MIN = 10;

function scrypt(password: string, salt: Buffer): Promise<Buffer> {
  return new Promise((resolve, reject) =>
    crypto.scrypt(password, salt, KEY_LENGTH, SCRYPT, (err, key) => (err ? reject(err) : resolve(key)))
  );
}

/** "scrypt$<salt hex>$<hash hex>". The plain password is never stored or logged. */
export async function hashPassword(password: string): Promise<string> {
  const salt = crypto.randomBytes(16);
  const key = await scrypt(password, salt);
  return `scrypt$${salt.toString("hex")}$${key.toString("hex")}`;
}

export async function verifyPassword(password: string, stored: string | null | undefined): Promise<boolean> {
  if (!stored) return false;
  const [scheme, saltHex, hashHex] = stored.split("$");
  if (scheme !== "scrypt" || !saltHex || !hashHex) return false;
  const expected = Buffer.from(hashHex, "hex");
  const key = await scrypt(password, Buffer.from(saltHex, "hex"));
  return key.length === expected.length && crypto.timingSafeEqual(key, expected);
}

/** Indonesian error message for the person, or null when the password is acceptable. */
export function passwordProblem(password: string, confirm: string, phoneE164?: string | null): string | null {
  if (password.length < PASSWORD_MIN) return `Password minimal ${PASSWORD_MIN} karakter.`;

    const local = `0${intl.slice(2)}`;
    if ([phoneE164, intl, local].includes(password)) return "Jangan pakai nomor HP sebagai password.";

  return null;
}
```

```ts
/**
 * A button attached to an assistant reply. Tools add them; each channel
 * renders them its own way (web: buttons in the bubble, WhatsApp: cta_url).
 * Paths only — the host is always our own site, so a tricked model can never
 * attach an outside payment link.
 */
export type ChatAction = { kind: "link"; label: string; path: string };

const SAFE_PATH = /^\/(?![/\\])[A-Za-z0-9\-._~/?=&%]*$/;
const MAX_ACTIONS = 5;
const MAX_LABEL = 20; // WhatsApp's button text limit

export function addAction(target: { actions: ChatAction[] }, label: string, path: string): void {
  if (!SAFE_PATH.test(path)) {
    throw new Error(`Refusing a button to "${path.slice(0, 60)}": only pages on this site are allowed.`);
  }
  const clean = label.trim().slice(0, MAX_LABEL);
  if (!clean) throw new Error("A button needs a label.");
  if (target.actions.length >= MAX_ACTIONS || target.actions.some((a) => a.path === path)) return;
  target.actions.push({ kind: "link", label: clean, path });
}

/** Reads actions back from a stored message, dropping anything malformed or unsafe. */
export function parseActions(raw: unknown): ChatAction[] {
  if (!Array.isArray(raw)) return [];
  return raw.flatMap((item) => {
    const a = item as Partial<ChatAction> | null;
    if (!a || a.kind !== "link" || typeof a.label !== "string" || typeof a.path !== "string") return [];
    if (!SAFE_PATH.test(a.path)) return [];
    return [{ kind: "link" as const, label: a.label.slice(0, MAX_LABEL), path: a.path }];
  });
}
```

```ts
import { Channel, MessageRole } from "@prisma/client";
import { env } from "@/env";
import { prisma } from "@/lib/prisma";
import { log } from "@/lib/logger";
import { maskPhone } from "@/lib/crypto";
import { notifyOwner } from "@/lib/notify";
import { LIMITS, overLimit } from "@/lib/rate-limit";
import type { ChatAction } from "./actions";
import { estimateCostUsd, runAssistant, withLog } from "./assistant";
import { saveMessage, type ChatCtx } from "./context";
import { BLOCKED_REPLY, guardReply, INJECTION_STRIKES, looksLikeInjection, OFF_TOPIC_REPLY } from "./rules";

export const RATE_REPLY_MINUTE = "Pelan-pelan ya kak 🙏 Tunggu sebentar lalu kirim lagi.";
export const RATE_REPLY_DAY = "Maaf kak, chat hari ini sudah cukup banyak. Admin akan menghubungi kakak ya 🙏";
export const ERROR_REPLY = "Maaf kak, sistemnya lagi bermasalah sebentar. Coba kirim ulang pesannya ya 🙏";

export type Reply = { text: string; actions: ChatAction[] };

/**
 * One inbound message, any channel: limits → save → injection filter →
 * assistant → output filter → save. Returns what to send, or null to stay silent.
 */
export async function handleInbound(ctx: ChatCtx, text: string, opts: { waMessageId?: string } = {}): Promise<Reply | null> {
  if (ctx.blocked) return null;

  // Cheap abuse limits before a single token is spent.
  if (await overLimit("chat-min", ctx.contactId, LIMITS.waPerMinute.limit, LIMITS.waPerMinute.windowMs)) {
    return ctx.channel === Channel.WEB ? { text: RATE_REPLY_MINUTE, actions: [] } : null;
  }
  if (await overLimit("chat-day", ctx.contactId, LIMITS.waPerDay.limit, LIMITS.waPerDay.windowMs)) {
    return { text: RATE_REPLY_DAY, actions: [] };
  }

  await saveMessage(ctx, MessageRole.USER, text, { waMessageId: opts.waMessageId });

  // A human is handling this WhatsApp chat — stay quiet.
  if (ctx.handoff && ctx.channel === Channel.WHATSAPP) return null;

  if (looksLikeInjection(text)) return refuseInjection(ctx);

  try {
    const result = await runAssistant(ctx);
    const guarded = guardReply(result.text, env().APP_URL);
    if (guarded.flagged.length) log.warn("reply filtered", { contactId: ctx.contactId, flagged: guarded.flagged });

    await saveMessage(ctx, MessageRole.ASSISTANT, withLog(guarded.text, result.toolLog), {
      toolLog: result.toolLog,
      actions: result.actions,
    });
    await prisma.auditLog.create({
      data: {
        actor: "bot",
        action: "reply",
        contactId: ctx.contactId,
        tenantId: ctx.tenantId,
        meta: {
          channel: ctx.channel,
          tools: result.toolLog.map((t) => t.tool),
          tokens: result.usage,
          costUsd: Number(estimateCostUsd(result.usage).toFixed(5)),
          ...(guarded.flagged.length ? { filtered: guarded.flagged } : {}),
        } as never,
      },
    });
    return { text: guarded.text, actions: result.actions };
  } catch (error) {
    log.error("assistant failed", { message: String(error) });
    return { text: ERROR_REPLY, actions: [] };
  }
}

/** Obvious prompt injection never reaches the model. Repeat offenders are muted for a day. */
async function refuseInjection(ctx: ChatCtx): Promise<Reply> {
  log.warn("injection attempt blocked", { contactId: ctx.contactId });
  await prisma.auditLog.create({ data: { actor: "bot", action: "blocked:injection", contactId: ctx.contactId } });

  const strikes = await prisma.auditLog.count({
    where: {
      contactId: ctx.contactId,
      action: "blocked:injection",
      createdAt: { gte: new Date(Date.now() - 86_400_000) },
    },
  });

  if (strikes < INJECTION_STRIKES) {
    await saveMessage(ctx, MessageRole.ASSISTANT, OFF_TOPIC_REPLY);
    return { text: OFF_TOPIC_REPLY, actions: [] };
  }

  await prisma.contact.update({
    where: { id: ctx.contactId },
    data: { blockedUntil: new Date(Date.now() + 86_400_000) },
  });
  await saveMessage(ctx, MessageRole.ASSISTANT, BLOCKED_REPLY);
  const who = ctx.phoneE164 ? maskPhone(ctx.phoneE164) : "pengunjung situs (anonim)";
  await notifyOwner({
    dedupeKey: `blocked:${ctx.contactId}:${new Date().toISOString().slice(0, 10)}`,
    title: "Nomor dijeda otomatis",
    subject: `Chat dijeda 24 jam: ${ctx.name ?? who}`,
    body: `${ctx.phoneE164 ?? "Pengunjung situs (anonim)"} mencoba memanipulasi asisten ${strikes} kali dalam 24 jam, jadi chatnya dijeda 24 jam.\n\nKalau ini salah paham, kosongkan blockedUntil untuk kontak ini.`,
    short: `${who} dijeda 24 jam karena mencoba memanipulasi asisten.`,
  });
  return { text: BLOCKED_REPLY, actions: [] };
}
```

```ts
import crypto from "node:crypto";
import { after, NextRequest, NextResponse } from "next/server";
import { env } from "@/env";
import { prisma } from "@/lib/prisma";
import { log } from "@/lib/logger";
import { safeEqual } from "@/lib/crypto";
import { whatsappEnabled } from "@/lib/features";
import { overLimit } from "@/lib/rate-limit";
import { markRead, sendCtaUrl, sendText } from "@/lib/whatsapp";
import { resolveWhatsAppContext } from "@/lib/chat/context";
import { handleInbound } from "@/lib/chat/pipeline";
import { TEXT_ONLY_REPLY } from "@/lib/chat/rules";

export const runtime = "nodejs";
export const dynamic = "force-dynamic";

/** Meta calls this once when you add the webhook URL. */
export async function GET(req: NextRequest) {
  if (!whatsappEnabled()) return new NextResponse("not found", { status: 404 });
  const params = req.nextUrl.searchParams;
  if (params.get("hub.mode") === "subscribe" && safeEqual(params.get("hub.verify_token") ?? "", env().WA_VERIFY_TOKEN)) {
    return new NextResponse(params.get("hub.challenge") ?? "", { status: 200 });
  }
  return new NextResponse("forbidden", { status: 403 });
}

export async function POST(req: NextRequest) {
  if (!whatsappEnabled()) return new NextResponse("not found", { status: 404 });
  const raw = await req.text();

  // 1. Only Meta may call this. Verified before anything is parsed.
  if (!validSignature(raw, req.headers.get("x-hub-signature-256"))) {
    log.warn("whatsapp webhook: bad signature");
    return new NextResponse("invalid signature", { status: 401 });
  }

  let body: WaWebhookBody;
  try {
    body = JSON.parse(raw) as WaWebhookBody;
  } catch {
    return NextResponse.json({ ok: true });
  }

  // Meta may batch several messages (even from several people) into one call.
  const inbound = (body.entry ?? []).flatMap((entry) =>
    (entry.changes ?? []).flatMap((change) =>
      (change.value?.messages ?? []).map((message) => ({ message, value: change.value! }))
    )
  );

  for (const { message, value } of inbound) {
    // 2. Meta retries aggressively. One message, one reply.
    try {
      await prisma.processedWebhook.create({ data: { key: `wa:${message.id}` } });
    } catch {
      continue;
    }
    // 3. Answer Meta inside its timeout, then do the slow work.
    after(() => handleMessage(message, value).catch((e) => log.error("handleMessage failed", { message: String(e) })));
  }

  return NextResponse.json({ ok: true });
}

async function handleMessage(message: WaMessage, value: WaValue) {
  const waId = message.from;
  await markRead(message.id);

  // Muted for repeated manipulation attempts: no reply, no tokens spent.
  const muted = await prisma.contact.findUnique({ where: { waId }, select: { blockedUntil: true } });
  if (muted?.blockedUntil && muted.blockedUntil > new Date()) return;

  // Media is never accepted in chat — KTP photos belong in the secure form.
  if (message.type !== "text" && message.type !== "interactive") {
    if (["image", "document", "video"].includes(message.type)) {
      await sendText(waId, "Demi keamanan, dokumen seperti KTP hanya diunggah lewat formulir aman ya kak, bukan lewat chat 🙏");
    } else if (["audio", "sticker", "location", "contacts"].includes(message.type)) {
      if (!(await overLimit("wa-nontext", waId, 3, 3_600_000))) await sendText(waId, TEXT_ONLY_REPLY);
    }
    return;
  }

  const text = extractText(message);
  if (!text) return;

  const ctx = await resolveWhatsAppContext(waId, value?.contacts?.[0]?.profile?.name);
  const reply = await handleInbound(ctx, text, { waMessageId: message.id });
  if (!reply) return;

  await sendText(waId, reply.text);
  for (const action of reply.actions) {
    await sendCtaUrl(waId, action.label, action.label, `${env().APP_URL}${action.path}`);
  }
}

function extractText(message: WaMessage): string {
  if (message.type === "text") return String(message.text?.body ?? "").slice(0, 600);
  const i = message.interactive;
  if (i?.type === "button_reply") return String(i.button_reply?.title ?? "").slice(0, 200);
  if (i?.type === "list_reply") return String(i.list_reply?.title ?? "").slice(0, 200);
  return "";
}

function validSignature(raw: string, header: string | null): boolean {
  if (!header) return false;
  const expected = "sha256=" + crypto.createHmac("sha256", env().WA_APP_SECRET).update(raw).digest("hex");
  const a = Buffer.from(header);
  const b = Buffer.from(expected);
  if (a.length !== b.length) return false;
  return crypto.timingSafeEqual(a, b);
}

/* Minimal shapes for the parts of Meta's payload we use. */
type WaMessage = {
  id: string;
  from: string;
  type: string;
  text?: { body?: string };
  interactive?: {
    type?: string;
    button_reply?: { id?: string; title?: string };
    list_reply?: { id?: string; title?: string };
  };
};
type WaValue = { contacts?: { profile?: { name?: string } }[]; messages?: WaMessage[] };
type WaWebhookBody = { entry?: { changes?: { value?: WaValue }[] }[] };
```

```ts
import type { NextRequest } from "next/server";
import { env } from "@/env";

/**
 * True when a state-changing request comes from our own pages. Browsers send
 * Origin on every POST, so a POST without one is treated as foreign.
 */
export function sameOrigin(req: NextRequest): boolean {
  const origin = req.headers.get("origin");
  if (!origin) return false;
  return origin === new URL(env().APP_URL).origin || origin === req.nextUrl.origin;
}

export function clientIp(req: NextRequest): string {
  const forwarded = req.headers.get("x-forwarded-for");
  return (forwarded?.split(",")[0] ?? req.headers.get("x-real-ip") ?? "0.0.0.0").trim();
}
```

```ts
import { Channel, ContactType, MessageRole } from "@prisma/client";
import { env } from "@/env";
import { prisma } from "@/lib/prisma";
import { whatsappEnabled } from "@/lib/features";
import { sendCtaUrl, sendText } from "@/lib/whatsapp";
import type { ChatAction } from "./actions";
import { currentConversation, MEMBER_TTL_MS, PROSPECT_TTL_MS, webRenterKey } from "./context";

/**
 * Puts a message from the kos into a contact's chat, as if the assistant said
 * it: it is waiting when they open the website chat, and it is also sent on
 * WhatsApp when that contact is a WhatsApp contact and WhatsApp is set up.
 */
export async function deliverToContact(contactId: string, text: string, actions: ChatAction[] = []): Promise<void> {
  const contact = await prisma.contact.findUnique({ where: { id: contactId } });
  if (!contact) return;

  const conversation = await currentConversation(contact.id, contact.type);
  const ttl = contact.type === ContactType.PROSPECT ? PROSPECT_TTL_MS : MEMBER_TTL_MS;
  await prisma.message.create({
    data: {
      conversationId: conversation.id,
      role: MessageRole.ASSISTANT,
      content: text.slice(0, 4000),
      actions: actions.length ? (actions as never) : undefined,
      expiresAt: new Date(Date.now() + ttl),
    },
  });

  if (contact.channel === Channel.WHATSAPP && contact.waId && whatsappEnabled()) {
    await sendText(contact.waId, text).catch(() => undefined);
    for (const a of actions) {
      await sendCtaUrl(contact.waId, a.label, a.label, `${env().APP_URL}${a.path}`).catch(() => undefined);
    }
  }
}

/** Every chat a renter has: their website chat (created if needed) and any WhatsApp contact. */
export async function deliverToRenter(tenantId: string, text: string, actions: ChatAction[] = []): Promise<void> {
  const tenant = await prisma.tenant.findUnique({ where: { id: tenantId } });
  if (!tenant) return;

  const key = webRenterKey(tenantId);
  const web = await prisma.contact.upsert({
    where: { webSessionId: key },
    create: {
      channel: Channel.WEB,
      webSessionId: key,
      displayName: tenant.fullName,
      type: ContactType.MEMBER,
      tenantId,
      verifiedAt: new Date(),
      expiresAt: null,
    },
    update: {},
  });
  const whatsapp = await prisma.contact.findMany({ where: { tenantId, channel: Channel.WHATSAPP }, select: { id: true } });

  for (const c of [web, ...whatsapp]) await deliverToContact(c.id, text, actions);
}
```

```ts
export type PaymentInput = {
  invoiceCode: string;
  /** Unique per payment event: "xendit:<id>" or "sim-<uuid>". Makes this idempotent. */
  eventId: string;
  amount: number;
  method: string;
  paidAt: Date;
  raw?: unknown;
};
export type PaymentOutcome = "duplicate" | "unknown_invoice" | "partial" | "paid";

/**
 * The ONLY place an invoice becomes paid. Called by the Xendit webhook and, in
 * development, by the fake payment page — so a simulated payment runs exactly
 * the code a real one does. The chatbot can never call this.
 */
export async function recordPayment(input: PaymentInput): Promise<PaymentOutcome> {
  try {
    await prisma.processedWebhook.create({ data: { key: `payment:${input.eventId}` } });
  } catch {
    return "duplicate";
  }

  const invoice = await prisma.invoice.findUnique({
    where: { code: input.invoiceCode },
    include: { application: true, lease: { include: { room: true } }, guestStay: true },
  });
  if (!invoice) {
    log.error("payment for unknown invoice", { invoice: input.invoiceCode });
    return "unknown_invoice";
  }

  const amount = Math.round(input.amount);
  await prisma.payment.create({
    data: {
      invoiceId: invoice.id,
      amount,
      method: input.method.slice(0, 40),
      gatewayRef: input.eventId,
      paidAt: input.paidAt,
      raw: (input.raw ?? {}) as never,
    },
  });

  const totalPaid = invoice.amountPaid + amount;
  const updated = await prisma.invoice.update({
    where: { id: invoice.id },
    data: { amountPaid: totalPaid, status: totalPaid >= invoice.amount ? InvoiceStatus.PAID : InvoiceStatus.PARTIAL },
  });
  if (updated.status !== InvoiceStatus.PAID) return "partial";

  try {
    if (invoice.kind === InvoiceKind.ONBOARDING && invoice.application) {
      await completeOnboarding(invoice.application.id, invoice.id, amount, updated.code);
    } else if (invoice.kind === InvoiceKind.GUEST && invoice.guestStay) {
      await approveGuest(invoice.guestStay.id, updated.code);
    } else if (invoice.lease) {
      await confirmRent(invoice.lease.tenantId, invoice.lease.room.code, amount, updated.code, invoice.description);
    }
  } catch (error) {
    log.error("post-payment handling failed", { invoice: updated.code, message: String(error) });
  }
  return "paid";
}

export async function expireInvoiceByCode(code: string): Promise<void> {
  await prisma.invoice.updateMany({
    where: { code, status: { in: [InvoiceStatus.UNPAID, InvoiceStatus.PARTIAL] } },
    data: { status: InvoiceStatus.EXPIRED },
  });
}
```

```ts
import { NextRequest, NextResponse } from "next/server";
import { env } from "@/env";
import { log } from "@/lib/logger";
import { safeEqual } from "@/lib/crypto";
import { paymentsLive } from "@/lib/features";
import { expireInvoiceByCode, recordPayment } from "@/lib/payments";

export const runtime = "nodejs";
export const dynamic = "force-dynamic";

/** Xendit tells us a payment landed. Verified here; everything else is recordPayment. */
export async function POST(req: NextRequest) {
  if (!paymentsLive()) return new NextResponse("not found", { status: 404 });

  const token = req.headers.get("x-callback-token") ?? "";
  if (!safeEqual(token, env().XENDIT_WEBHOOK_TOKEN)) {
    log.warn("xendit webhook: bad callback token");
    return new NextResponse("invalid token", { status: 401 });
  }

  const event = (await req.json().catch(() => null)) as XenditEvent | null;
  if (!event?.id || !event.external_id) return NextResponse.json({ ok: true });

  if (event.status === "EXPIRED") {
    await expireInvoiceByCode(event.external_id);
    return NextResponse.json({ ok: true });
  }
  if (event.status !== "PAID" && event.status !== "SETTLED") return NextResponse.json({ ok: true });

  await recordPayment({
    invoiceCode: event.external_id,
    eventId: `xendit:${event.id}`,
    amount: Number(event.paid_amount ?? event.amount ?? 0),
    method: String(event.payment_method ?? event.payment_channel ?? "UNKNOWN"),
    paidAt: event.paid_at ? new Date(event.paid_at) : new Date(),
    raw: event,
  });
  return NextResponse.json({ ok: true });
}

type XenditEvent = {
  id: string;
  external_id: string;
  status: string;
  amount?: number;
  paid_amount?: number;
  paid_at?: string;
  payment_method?: string;
  payment_channel?: string;
};
```

```ts
/** Runs the real post-payment code with a simulated payment. Development only. */
export async function POST(req: NextRequest) {
  if (!fakePaymentsAllowed()) return new NextResponse("not found", { status: 404 });
  if (!sameOrigin(req)) return new NextResponse("forbidden", { status: 403 });

  const form = await req.formData();
  const code = String(form.get("code") ?? "").toUpperCase();
  const outcome = String(form.get("outcome") ?? "");
  if (!/^[A-Z0-9-]{6,40}$/.test(code)) return new NextResponse("bad request", { status: 400 });

  const invoice = await prisma.invoice.findUnique({ where: { code } });
  if (!invoice) return new NextResponse("not found", { status: 404 });

  if (outcome === "expire") {
    await expireInvoiceByCode(code);
    return NextResponse.redirect(new URL(`/dev/pay/${code}`, req.url), { status: 303 });
  }

  if (invoice.status !== InvoiceStatus.PAID) {
    await recordPayment({
      invoiceCode: code,
      eventId: `sim-${crypto.randomUUID()}`,
      amount: invoice.amount - invoice.amountPaid,
      method: "SIMULATED",
      paidAt: new Date(),
      raw: { simulated: true },
    });
  }
  return NextResponse.redirect(new URL(`/paid/${code}`, req.url), { status: 303 });
}
```

```ts
import { MessageRole } from "@prisma/client";
import { prisma } from "@/lib/prisma";
import { parseActions, type ChatAction } from "./actions";
import { stripLog } from "./assistant";

export type ChatLine = { role: "user" | "assistant"; text: string; actions: ChatAction[] };

/** What the website chat shows when it opens: the latest 50 messages still within retention. */
export async function webTranscript(contactId: string): Promise<ChatLine[]> {
  const now = new Date();
  const rows = await prisma.message.findMany({
    where: { conversation: { contactId }, OR: [{ expiresAt: null }, { expiresAt: { gt: now } }] },
    orderBy: { createdAt: "desc" },
    take: 50,
    select: { role: true, content: true, actions: true },
  });
  return rows.reverse().map((m) =>
    m.role === MessageRole.USER
      ? { role: "user" as const, text: m.content, actions: [] }
      : { role: "assistant" as const, text: stripLog(m.content), actions: parseActions(m.actions) }
  );
}
```

```ts
import crypto from "node:crypto";
import { cookies } from "next/headers";
import type { NextResponse } from "next/server";
import { readSigned, signSession } from "./crypto";

export const CHAT_COOKIE = "kos_chat";
const CHAT_TTL_MS = 30 * 86_400_000;
const ANON_ID = /^[A-Za-z0-9_-]{20,64}$/;

/** The anonymous visitor id from the signed cookie, or null (missing, tampered or expired). */
export async function readAnonId(): Promise<string | null> {
  const jar = await cookies();
  const id = readSigned(jar.get(CHAT_COOKIE)?.value);
  return id && ANON_ID.test(id) ? id : null;
}

export function newAnonId(): { id: string; cookie: string } {
  const id = crypto.randomBytes(24).toString("base64url");
  return { id, cookie: signSession(id, CHAT_TTL_MS) };
}

export function setChatCookie(res: NextResponse, cookie: string): void {
  res.cookies.set(CHAT_COOKIE, cookie, {
    httpOnly: true,
    sameSite: "lax",
    secure: process.env.NODE_ENV === "production",
    path: "/",
    maxAge: CHAT_TTL_MS / 1000,
  });
}
```

```ts
import { NextRequest, NextResponse } from "next/server";
import { z } from "zod";
import { findWebContactId, resolveWebContext } from "@/lib/chat/context";
import { handleInbound, RATE_REPLY_MINUTE } from "@/lib/chat/pipeline";
import { BLOCKED_REPLY } from "@/lib/chat/rules";
import { webTranscript } from "@/lib/chat/transcript";
import { clientIp, sameOrigin } from "@/lib/http";
import { overLimit } from "@/lib/rate-limit";
import { newAnonId, readAnonId, setChatCookie } from "@/lib/web-session";

export const runtime = "nodejs";
export const dynamic = "force-dynamic";

const bodySchema = z.object({ message: z.string().trim().min(1).max(600) });

/** The conversation so far, for when the chat window opens. Creates nothing. */
export async function GET() {
  const anonId = await readAnonId();
  const tenantId: string | null = null;
  const contactId = await findWebContactId({ anonId, tenantId });
  return NextResponse.json(
    { messages: contactId ? await webTranscript(contactId) : [], renter: null },
    { headers: { "cache-control": "no-store" } }
  );
}

/** One message from the website chat. Same pipeline as WhatsApp. */
export async function POST(req: NextRequest) {
  if (!sameOrigin(req)) return NextResponse.json({ error: "forbidden" }, { status: 403 });

  if (await overLimit("chat-ip", clientIp(req), 60, 60_000)) {
    return NextResponse.json({ reply: RATE_REPLY_MINUTE, actions: [] }, { status: 429 });
  }

  const parsed = bodySchema.safeParse(await req.json().catch(() => null));
  if (!parsed.success) {
    return NextResponse.json({ error: "Pesan kosong atau terlalu panjang (maks. 600 karakter)." }, { status: 400 });
  }

  let anonId = await readAnonId();
  let newCookie: string | null = null;
  if (!anonId) {
    const fresh = newAnonId();
    anonId = fresh.id;
    newCookie = fresh.cookie;
  }

  const tenantId: string | null = null;
  const ctx = await resolveWebContext({ anonId, tenantId });
  const reply = await handleInbound(ctx, parsed.data.message);

  const res = NextResponse.json({ reply: reply?.text ?? BLOCKED_REPLY, actions: reply?.actions ?? [] });
  if (newCookie) setChatCookie(res, newCookie);
  return res;
}
```

```tsx
  );
```

```ts
import { cookies } from "next/headers";
import type { NextResponse } from "next/server";
import { prisma } from "./prisma";
import { readSigned, signSession } from "./crypto";

export const RENTER_COOKIE = "kos_renter";
const RENTER_TTL_MS = 7 * 86_400_000;

export type Renter = { id: string; fullName: string };

/** "<tenantId>:<sessionVersion>", signed. Bumping sessionVersion logs out every device. */
export function renterCookieValue(tenantId: string, sessionVersion: number): string {
  return signSession(`${tenantId}:${sessionVersion}`, RENTER_TTL_MS);
}

export async function renterFromCookie(value: string | undefined): Promise<Renter | null> {
  const payload = readSigned(value);
  if (!payload) return null;
  const [id, version] = payload.split(":");
  if (!id || !version) return null;
  const tenant = await prisma.tenant.findUnique({
    where: { id },
    select: { id: true, fullName: true, sessionVersion: true },
  });
  if (!tenant || String(tenant.sessionVersion) !== version) return null;
  return { id: tenant.id, fullName: tenant.fullName };
}

export async function currentRenter(): Promise<Renter | null> {
  const jar = await cookies();
  return renterFromCookie(jar.get(RENTER_COOKIE)?.value);
}

export function setRenterCookie(res: NextResponse, value: string): void {
  res.cookies.set(RENTER_COOKIE, value, {
    httpOnly: true,
    sameSite: "lax",
    secure: process.env.NODE_ENV === "production",
    path: "/",
    maxAge: RENTER_TTL_MS / 1000,
  });
}

export function clearRenterCookie(res: NextResponse): void {
  res.cookies.set(RENTER_COOKIE, "", { httpOnly: true, path: "/", maxAge: 0 });
}
```

```ts
import { prisma } from "@/lib/prisma";
import { log } from "@/lib/logger";
import { normalizePhone } from "@/lib/money";
import { clientIp, sameOrigin } from "@/lib/http";
import { hashPassword, verifyPassword } from "@/lib/password";
import { atLimit, LIMITS, overLimit } from "@/lib/rate-limit";
import { renterCookieValue, setRenterCookie } from "@/lib/renter-auth";

export const runtime = "nodejs";
export const dynamic = "force-dynamic";

// Checked when the phone is unknown, so a wrong phone takes as long as a wrong password.
let dummyHash: Promise<string> | null = null;

export async function POST(req: NextRequest) {
  if (!sameOrigin(req)) return new NextResponse("forbidden", { status: 403 });
  const back = (query: string) => NextResponse.redirect(new URL(`/masuk?${query}`, req.url), { status: 303 });

  const ip = clientIp(req);
  const form = await req.formData();
  const phone = normalizePhone(String(form.get("phone") ?? ""));
  const password = String(form.get("password") ?? "").slice(0, 200);
  const { limit, windowMs } = LIMITS.renterLogin;

  if ((await atLimit("login-ip", ip, limit, windowMs)) || (phone && (await atLimit("login-phone", phone, limit, windowMs)))) {
    return back("locked=1");
  }

  const tenant = phone ? await prisma.tenant.findUnique({ where: { phoneE164: phone } }) : null;
  const ok = tenant?.passwordHash
    ? await verifyPassword(password, tenant.passwordHash)
    : (await verifyPassword(password, await (dummyHash ??= hashPassword("not-a-real-password"))), false);

  if (!tenant || !ok) {
    await overLimit("login-ip", ip, limit, windowMs);
    if (phone) await overLimit("login-phone", phone, limit, windowMs);
    log.warn("renter login failed");
    return back("error=1");
  }

  await prisma.auditLog.create({ data: { actor: "tenant", action: "renter:login", tenantId: tenant.id } });
  const res = NextResponse.redirect(new URL("/?chat=1", req.url), { status: 303 });
  setRenterCookie(res, renterCookieValue(tenant.id, tenant.sessionVersion));
  return res;
}
```

```ts
import { env } from "@/env";
import { prisma } from "./prisma";
import { newToken, sha256 } from "./crypto";
import { hashPassword, passwordProblem } from "./password";

const TTL_MS = 24 * 3_600_000;
const INVALID = "Link sudah dipakai atau kedaluwarsa. Minta link baru ke pemilik kos ya kak.";

/** A single-use link the owner copies and sends to the renter. Only its hash is stored. */
export async function createPasswordSetupLink(tenantId: string): Promise<string> {
  const { raw, hash } = newToken();
  await prisma.passwordSetupToken.create({
    data: { tenantId, tokenHash: hash, expiresAt: new Date(Date.now() + TTL_MS) },
  });
  return `${env().APP_URL}/atur-password/${raw}`;
}

export async function findSetupToken(raw: string) {
  if (!/^[A-Za-z0-9_-]{20,64}$/.test(raw)) return null;
  const row = await prisma.passwordSetupToken.findUnique({
    where: { tokenHash: sha256(raw) },
    include: { tenant: { select: { id: true, fullName: true, phoneE164: true } } },
  });
  if (!row || row.usedAt || row.expiresAt < new Date()) return null;
  return row;
}

/** Sets the password, burns every open link for this renter, and logs out all their devices. */
export async function consumePasswordSetup(
  raw: string,
  password: string,
  confirm: string
): Promise<{ ok: true } | { ok: false; error: string }> {
  const row = await findSetupToken(raw);
  if (!row) return { ok: false, error: INVALID };

  const problem = passwordProblem(password, confirm, row.tenant.phoneE164);
  if (problem) return { ok: false, error: problem };
  const passwordHash = await hashPassword(password);

    prisma.tenant.update({
      where: { id: row.tenantId },
      data: { passwordHash, sessionVersion: { increment: 1 } },
    }),
    prisma.passwordSetupToken.updateMany({ where: { tenantId: row.tenantId, usedAt: null }, data: { usedAt: now } }),
```

```ts
import { RoomStatus } from "@prisma/client";
import { z, type ZodError } from "zod";

const int = (min: number, max: number) => z.coerce.number().int().min(min).max(max);
const text = (min: number, max: number) => z.string().trim().min(min).max(max);
const list = z.array(z.string().max(300)).max(40);
const lines = (v: FormDataEntryValue | null) =>
  String(v ?? "")
    .split(/\r?\n/)
    .map((l) => l.trim())
    .filter(Boolean);

export const propertySchema = z.object({
  name: text(2, 80),
  tagline: text(2, 140),
  address: text(5, 200),
  // https only: the site renders this as a link, so javascript: and friends must never get in.
  mapsUrl: z.union([z.literal(""), z.string().trim().max(500).regex(/^https:\/\/[^\s"<>]+$/, "harus diawali https://")]),
  guestFeePerNight: int(0, 10_000_000),
  lateFeePerDay: int(0, 10_000_000),
  lateFeeMax: int(0, 100_000_000),
  electricQuota: int(0, 10_000),
  electricRate: int(0, 100_000),
  dueDayOfMonth: int(1, 28),
  yearlyMonths: int(1, 12),
  minMonths: int(1, 24),
  guestCutoffHour: int(0, 23),
  maxGuestNights: int(1, 30),
  maxGuestsAtOnce: int(1, 10),
  depositMonths: int(0, 6),
  depositReturnDays: int(0, 90),
  utilitiesNote: text(2, 200),
  houseRules: list,
  paymentTerms: list,
  guestRules: list,
  facilities: list,
});

export function parseProperty(form: FormData) {
  const raw: Record<string, unknown> = Object.fromEntries(form.entries());
  for (const key of ["houseRules", "paymentTerms", "guestRules", "facilities"]) raw[key] = lines(form.get(key));
  return propertySchema.safeParse(raw);
}

export const roomSchema = z.object({
  code: z.string().trim().toUpperCase().regex(/^[A-Z0-9-]{2,12}$/, "huruf, angka, dan tanda - saja"),
  type: text(2, 40),
  floor: int(0, 50),
  sizeLabel: text(1, 40),
  monthlyPrice: int(100_000, 100_000_000),
  bathroom: text(2, 80),
  extras: z.string().trim().max(300),
  description: z.string().trim().max(1500),
  status: z.nativeEnum(RoomStatus),
  availableOn: z.union([z.literal(""), z.string().regex(/^\d{4}-\d{2}-\d{2}$/)]),
  sortOrder: int(0, 999),
  hidden: z.boolean(),
});

export function parseRoom(form: FormData) {
  return roomSchema.safeParse({ ...Object.fromEntries(form.entries()), hidden: form.get("hidden") === "on" });
}

export const listItemSchema = z.object({ a: text(1, 200), b: text(1, 1500) });

export function parseListItem(form: FormData) {
  return listItemSchema.safeParse({ a: form.get("a") ?? "", b: form.get("b") ?? "" });
}

/** Services, nearby places and FAQ share one editor: two text fields per row. */
export const LIST_KINDS = {
  layanan: { title: "Layanan berbayar", a: "Nama layanan", b: "Harga / keterangan" },
  sekitar: { title: "Sekitar kos", a: "Tempat", b: "Jarak" },
  faq: { title: "FAQ", a: "Pertanyaan", b: "Jawaban" },
} as const;
export type ListKind = keyof typeof LIST_KINDS;

export function firstIssue(error: ZodError): string {
  const issue = error.issues[0];
  return issue ? `${issue.path.join(".") || "form"}: ${issue.message}` : "Data tidak valid";
}
```

```ts
import { backTo, ownerPostGuard } from "@/lib/admin-guard";
import { firstIssue, parseProperty } from "@/lib/admin-forms";

export const runtime = "nodejs";

export async function POST(req: NextRequest) {
  const denied = await ownerPostGuard(req);
  if (denied) return denied;

  const parsed = parseProperty(await req.formData());
  if (!parsed.success) return backTo(req, "/admin/data", `error=${encodeURIComponent(firstIssue(parsed.error))}`);

  await prisma.propertySetting.update({

    data: { ...parsed.data, mapsUrl: parsed.data.mapsUrl || null },
  });
  await prisma.auditLog.create({ data: { actor: "owner", action: "data:property" } });
  return backTo(req, "/admin/data", "saved=1");
}
```

```ts
import { NextRequest } from "next/server";
import { Prisma, RoomStatus } from "@prisma/client";
import { prisma } from "@/lib/prisma";
import { backTo, ownerPostGuard } from "@/lib/admin-guard";
import { firstIssue, parseRoom } from "@/lib/admin-forms";
import { deleteObject } from "@/lib/storage";

export const runtime = "nodejs";

export async function POST(req: NextRequest) {
  const denied = await ownerPostGuard(req);
  if (denied) return denied;

  const form = await req.formData();
  const op = String(form.get("op") ?? "");
  const id = String(form.get("id") ?? "");
  const back = (query: string) => backTo(req, id && op !== "delete" ? `/admin/data/kamar/${id}` : "/admin/data/kamar", query);
  const fail = (message: string) => back(`error=${encodeURIComponent(message)}`);

  if (op === "delete") {
    const room = await prisma.room.findUnique({
      where: { id },
      include: { _count: { select: { leases: true, applications: true } }, photos: true },
    });
    if (!room) return fail("Kamar tidak ditemukan");
    if (room._count.leases || room._count.applications) {
      return backTo(req, `/admin/data/kamar/${id}`, `error=${encodeURIComponent("Kamar ini punya riwayat kontrak — sembunyikan saja")}`);
    }
    await prisma.room.delete({ where: { id } });
    for (const p of room.photos) await deleteObject(p.key).catch(() => undefined);
    await prisma.auditLog.create({ data: { actor: "owner", action: "data:room:delete", meta: { room: room.code } as never } });
    return back("saved=1");
  }

  const parsed = parseRoom(form);
  if (!parsed.success) return fail(firstIssue(parsed.error));
  const { availableOn, ...rest } = parsed.data;
  const data = {
    ...rest,
    availableOn: rest.status === RoomStatus.AVAILABLE || !availableOn ? null : new Date(`${availableOn}T00:00:00Z`),
  };

  try {
    if (op === "create") {
      const room = await prisma.room.create({ data });
      await prisma.auditLog.create({ data: { actor: "owner", action: "data:room:create", meta: { room: room.code } as never } });
      return backTo(req, `/admin/data/kamar/${room.id}`, "saved=1");
    }
    if (op === "update") {
      const active = await prisma.lease.findFirst({ where: { roomId: id, status: "ACTIVE" }, select: { id: true } });
      if (active && data.status === RoomStatus.AVAILABLE) return fail("Kamar ini masih punya penghuni aktif");
      const room = await prisma.room.update({ where: { id }, data });
      await prisma.auditLog.create({ data: { actor: "owner", action: "data:room:update", meta: { room: room.code } as never } });
      return back("saved=1");
    }
  } catch (e) {
```

```ts
import { NextRequest } from "next/server";
import { prisma } from "@/lib/prisma";
import { backTo, ownerPostGuard } from "@/lib/admin-guard";
import { firstIssue, LIST_KINDS, parseListItem, type ListKind } from "@/lib/admin-forms";

export const runtime = "nodejs";

type Row = { id: string; sortOrder: number };
type ListStore = {
  rows(): Promise<Row[]>;
  create(a: string, b: string, sortOrder: number): Promise<unknown>;
  update(id: string, a: string, b: string): Promise<unknown>;
  remove(id: string): Promise<unknown>;
  setOrder(id: string, sortOrder: number): Promise<unknown>;
};

/** One adapter per table, so the route below never touches a dynamic Prisma delegate. */
function store(kind: ListKind): ListStore {
  const order = { orderBy: { sortOrder: "asc" as const }, select: { id: true, sortOrder: true } };
  switch (kind) {
    case "layanan":
      return {
        rows: () => prisma.service.findMany(order),
        create: (a, b, sortOrder) => prisma.service.create({ data: { name: a, priceNote: b, sortOrder } }),
        update: (id, a, b) => prisma.service.update({ where: { id }, data: { name: a, priceNote: b } }),
        remove: (id) => prisma.service.delete({ where: { id } }),
        setOrder: (id, sortOrder) => prisma.service.update({ where: { id }, data: { sortOrder } }),
      };
    case "sekitar":
      return {
        rows: () => prisma.nearbyPlace.findMany(order),
        create: (a, b, sortOrder) => prisma.nearbyPlace.create({ data: { name: a, distance: b, sortOrder } }),
        update: (id, a, b) => prisma.nearbyPlace.update({ where: { id }, data: { name: a, distance: b } }),
        remove: (id) => prisma.nearbyPlace.delete({ where: { id } }),
        setOrder: (id, sortOrder) => prisma.nearbyPlace.update({ where: { id }, data: { sortOrder } }),
      };
    case "faq":
      return {
        rows: () => prisma.faqEntry.findMany(order),
        create: (a, b, sortOrder) => prisma.faqEntry.create({ data: { question: a, answer: b, sortOrder } }),
        update: (id, a, b) => prisma.faqEntry.update({ where: { id }, data: { question: a, answer: b } }),
        remove: (id) => prisma.faqEntry.delete({ where: { id } }),
        setOrder: (id, sortOrder) => prisma.faqEntry.update({ where: { id }, data: { sortOrder } }),
      };
  }
}

export async function POST(req: NextRequest, ctx: { params: Promise<{ kind: string }> }) {
  const denied = await ownerPostGuard(req);
  if (denied) return denied;

  const { kind } = await ctx.params;
  if (!(kind in LIST_KINDS)) return backTo(req, "/admin/data");
  const s = store(kind as ListKind);
  const path = `/admin/data/${kind}`;

  const form = await req.formData();
  const op = String(form.get("op") ?? "");
  const id = String(form.get("id") ?? "");
  const rows = await s.rows();

  if (op === "create" || op === "update") {
    const parsed = parseListItem(form);
    if (!parsed.success) return backTo(req, path, `error=${encodeURIComponent(firstIssue(parsed.error))}`);
    if (op === "create") await s.create(parsed.data.a, parsed.data.b, (rows.at(-1)?.sortOrder ?? -1) + 1);
    else if (rows.some((r) => r.id === id)) await s.update(id, parsed.data.a, parsed.data.b);
  } else if (op === "delete" && rows.some((r) => r.id === id)) {
    await s.remove(id);
  } else if (op === "up" || op === "down") {
    // Renumber 0..n so swaps always work even if old rows share a sortOrder.
    const index = rows.findIndex((r) => r.id === id);
    const swap = op === "up" ? index - 1 : index + 1;
    if (index >= 0 && swap >= 0 && swap < rows.length) {
      const ordered = rows.map((r) => r.id);
      [ordered[index], ordered[swap]] = [ordered[swap], ordered[index]];
      for (const [i, rowId] of ordered.entries()) await s.setOrder(rowId, i);
    }
  }

  await prisma.auditLog.create({ data: { actor: "owner", action: `data:${kind}:${op}` } });
  return backTo(req, path, "saved=1");
}
```

```ts
/** Validates an uploaded image by magic bytes, not by the filename. */
export function validateImage(buf: Buffer, declaredType: string, maxBytes = MAX_UPLOAD_BYTES) {
  if (buf.byteLength > maxBytes) throw new Error(`Ukuran file maksimal ${Math.round(maxBytes / 1024 / 1024)} MB.`);
  if (!ALLOWED_IMAGE.has(declaredType)) throw new Error("Format harus JPG, PNG, atau WEBP.");
  const isJpeg = buf[0] === 0xff && buf[1] === 0xd8 && buf[2] === 0xff;
  const isPng = buf.subarray(0, 8).equals(Buffer.from([0x89, 0x50, 0x4e, 0x47, 0x0d, 0x0a, 0x1a, 0x0a]));
  const isWebp = buf.subarray(0, 4).toString() === "RIFF" && buf.subarray(8, 12).toString() === "WEBP";
  if (!isJpeg && !isPng && !isWebp) throw new Error("File bukan gambar yang valid.");
  return isJpeg ? "image/jpeg" : isPng ? "image/png" : "image/webp";
}
```

```ts
import crypto from "node:crypto";
import sharp from "sharp";
import { prisma } from "./prisma";
import { deleteObject, putObject, validateImage } from "./storage";

export const PHOTO_MAX_BYTES = 8 * 1024 * 1024;
const MAX_SIDE = 1600;
/** 40 megapixels: enough for any phone photo, refuses decompression bombs. */
const MAX_INPUT_PIXELS = 40_000_000;
export const PHOTO_NAME = /^[A-Za-z0-9_-]{8,64}\.webp$/;

/**
 * Every uploaded photo is decoded and re-encoded: WEBP, longest side 1600px,
 * orientation applied, and all metadata (EXIF, GPS, camera serials) dropped —
 * sharp writes none unless asked.
 */
export async function processPhoto(input: Buffer, declaredType: string) {
  validateImage(input, declaredType, PHOTO_MAX_BYTES);
  const { data, info } = await sharp(input, { limitInputPixels: MAX_INPUT_PIXELS })
    .rotate()
    .resize({ width: MAX_SIDE, height: MAX_SIDE, fit: "inside", withoutEnlargement: true })
    .webp({ quality: 82 })
    .toBuffer({ resolveWithObject: true });
  return { data, width: info.width, height: info.height };
}

export const photoUrl = (key: string) => `/${key}`;

/** Room photo (roomId) or property gallery photo (null). The first one becomes the cover. */
export async function addPhoto(opts: { roomId: string | null; file: File; caption: string }) {
  const { data, width, height } = await processPhoto(Buffer.from(await opts.file.arrayBuffer()), opts.file.type);
  const key = `photos/${crypto.randomBytes(12).toString("base64url")}.webp`;
  await putObject(key, data, "image/webp");
  const count = await prisma.photo.count({ where: { roomId: opts.roomId } });
  return prisma.photo.create({
    data: {
      roomId: opts.roomId,
      caption: opts.caption.trim().slice(0, 140),
      key,
      width,
      height,
      sortOrder: count,
      isCover: count === 0,
    },
  });
}

export async function removePhoto(id: string) {
  const photo = await prisma.photo.delete({ where: { id } });
  await deleteObject(photo.key).catch(() => undefined);
  if (photo.isCover) {
    const next = await prisma.photo.findFirst({ where: { roomId: photo.roomId }, orderBy: { sortOrder: "asc" } });
    if (next) await prisma.photo.update({ where: { id: next.id }, data: { isCover: true } });
  }
  return photo;
}

export async function setCover(id: string) {
  const photo = await prisma.photo.findUniqueOrThrow({ where: { id } });
  await prisma.$transaction([
    prisma.photo.updateMany({ where: { roomId: photo.roomId }, data: { isCover: false } }),
    prisma.photo.update({ where: { id }, data: { isCover: true } }),
  ]);
  return photo;
}

export async function movePhoto(id: string, direction: -1 | 1) {
  const photo = await prisma.photo.findUniqueOrThrow({ where: { id } });
  const siblings = await prisma.photo.findMany({ where: { roomId: photo.roomId }, orderBy: { sortOrder: "asc" } });
  const index = siblings.findIndex((p) => p.id === id);
  const swap = index + direction;
  if (swap < 0 || swap >= siblings.length) return photo;
  const ordered = siblings.map((p) => p.id);
  [ordered[index], ordered[swap]] = [ordered[swap], ordered[index]];
  await prisma.$transaction(ordered.map((pid, i) => prisma.photo.update({ where: { id: pid }, data: { sortOrder: i } })));
  return photo;
}
```

```ts
import { NextRequest } from "next/server";
import { prisma } from "@/lib/prisma";
import { backTo, ownerPostGuard } from "@/lib/admin-guard";
import { addPhoto, movePhoto, removePhoto, setCover } from "@/lib/photos";

export const runtime = "nodejs";
export const maxDuration = 60;

export async function POST(req: NextRequest) {
  const denied = await ownerPostGuard(req);
  if (denied) return denied;

  const form = await req.formData();
  const op = String(form.get("op") ?? "");
  const backParam = String(form.get("back") ?? "");
  const back = /^\/admin\/data(\/[A-Za-z0-9/_-]*)?$/.test(backParam) ? backParam : "/admin/data/foto";
  const done = (query: string) => backTo(req, back, query);

  if (op === "upload") {
    const roomId = String(form.get("roomId") ?? "") || null;
    if (roomId && !(await prisma.room.findUnique({ where: { id: roomId }, select: { id: true } }))) {
      return done(`error=${encodeURIComponent("Kamar tidak ditemukan")}`);
    }
    const files = form.getAll("files").filter((f): f is File => f instanceof File && f.size > 0).slice(0, 12);
    if (!files.length) return done(`error=${encodeURIComponent("Pilih foto dulu")}`);
    const caption = String(form.get("caption") ?? "");
    const failed: string[] = [];
    for (const file of files) {
      try {
        await addPhoto({ roomId, file, caption });
      } catch (e) {
        failed.push(`${file.name.slice(0, 40)}: ${(e as Error).message}`);
      }
    }
    await prisma.auditLog.create({ data: { actor: "owner", action: "photo:upload", meta: { roomId, count: files.length - failed.length } as never } });
    return failed.length ? done(`error=${encodeURIComponent(failed.join("; "))}`) : done("saved=1");
  }

  const id = String(form.get("id") ?? "");
  if (!(await prisma.photo.findUnique({ where: { id }, select: { id: true } }))) {
    return done(`error=${encodeURIComponent("Foto tidak ditemukan")}`);
  }
  if (op === "caption") await prisma.photo.update({ where: { id }, data: { caption: String(form.get("caption") ?? "").trim().slice(0, 140) } });
  else if (op === "cover") await setCover(id);
  else if (op === "up") await movePhoto(id, -1);
  else if (op === "down") await movePhoto(id, 1);
  else if (op === "delete") await removePhoto(id);
  else return done(`error=${encodeURIComponent("Aksi tidak dikenal")}`);

  await prisma.auditLog.create({ data: { actor: "owner", action: `photo:${op}`, meta: { id } as never } });
  return done("saved=1");
}
```

```tsx
import { redirect } from "next/navigation";
import { MessageRole } from "@prisma/client";
import { env } from "@/env";
import { prisma } from "@/lib/prisma";
import { isOwner } from "@/lib/auth";
import { guardReply } from "@/lib/chat/rules";
import { stripLog } from "@/lib/chat/assistant";
import { parseActions } from "@/lib/chat/actions";

export const dynamic = "force-dynamic";
export const metadata = { title: "Percakapan", robots: { index: false, follow: false } };

/** Masks full ID and phone numbers in anything a visitor typed, before the owner sees it. */
const mask = (text: string) => guardReply(text, env().APP_URL).text;

/**
 * Read-only transcripts so the owner can see what people ask and how the
 * assistant answers. Prospect chats disappear 24 hours after their last message.
 */
export default async function ConversationsPage() {
  if (!(await isOwner())) redirect("/admin/login");

  const contacts = await prisma.contact.findMany({
    where: { conversations: { some: { messages: { some: {} } } } },
    orderBy: { lastMessageAt: "desc" },
    take: 50,
    include: { tenant: { include: { leases: { where: { status: "ACTIVE" }, include: { room: true }, take: 1 } } } },
  });

  const transcripts = await Promise.all(
    contacts.map((c) =>
      prisma.message.findMany({
        where: { conversation: { contactId: c.id } },
        orderBy: { createdAt: "asc" },
        take: 60,
        select: { id: true, role: true, content: true, toolLog: true, actions: true, createdAt: true },
      })
    )
  );
  // Blocked manipulation attempts, and replies the output filter had to change.
  const audit = await prisma.auditLog.findMany({
    where: { contactId: { in: contacts.map((c) => c.id) }, action: { in: ["blocked:injection", "reply"] } },
    select: { contactId: true, action: true, meta: true },
  });
  const flags = audit.filter(
    (row) => row.action === "blocked:injection" || Boolean((row.meta as { filtered?: unknown } | null)?.filtered)
  );

  return (
    <main className="wrap" style={{ padding: "26px 20px 60px" }}>
      <header style={{ display: "flex", alignItems: "center", gap: 14, marginBottom: 6, flexWrap: "wrap" }}>
        <h1 style={{ fontSize: 24 }}>Percakapan</h1>
        <a className="btn" href="/admin" style={{ marginLeft: "auto" }}>← Dashboard</a>
      </header>
      <p className="muted small" style={{ marginTop: 0 }}>
        50 percakapan terakhir. Chat calon penghuni otomatis terhapus 24 jam setelah pesan terakhir. Nomor KTP dan HP disamarkan.
      </p>

      {contacts.length === 0 && <p className="muted">Belum ada percakapan.</p>}

      {contacts.map((c, i) => {
        const lease = c.tenant?.leases[0];
        const who = c.tenant ? `${c.tenant.fullName}${lease ? ` · kamar ${lease.room.code}` : ""}` : c.displayName ?? "Pengunjung";
        const flagCount = flags.filter((f) => f.contactId === c.id).length;
        return (
          <details key={c.id} className="card" style={{ padding: "14px 18px", marginBottom: 10 }}>
            <summary style={{ cursor: "pointer", display: "flex", gap: 8, alignItems: "center", flexWrap: "wrap" }}>
              <strong>{who}</strong>
              <span className="pill pill-mute">{c.channel === "WEB" ? "situs" : "WhatsApp"}</span>
              <span className="pill pill-mute">{c.type === "MEMBER" ? "penghuni" : "calon"}</span>
              {flagCount > 0 && <span className="pill pill-warn">{flagCount} ditandai</span>}
              <time className="small muted" style={{ marginLeft: "auto" }}>
                {c.lastMessageAt.toLocaleString("id-ID", { dateStyle: "medium", timeStyle: "short" })}
              </time>
            </summary>
            <div style={{ display: "flex", flexDirection: "column", gap: 8, marginTop: 12 }}>
              {transcripts[i].map((m) => {
                const tools = Array.isArray(m.toolLog) ? (m.toolLog as { tool: string; ok: boolean }[]) : [];
                const actions = parseActions(m.actions);
                return (
                  <div key={m.id} className={`chat-bubble chat-${m.role === MessageRole.USER ? "user" : "assistant"}`} style={{ maxWidth: "80%" }}>
                    <div style={{ whiteSpace: "pre-wrap" }}>{mask(m.role === MessageRole.USER ? m.content : stripLog(m.content))}</div>
                    {(tools.length > 0 || actions.length > 0) && (
                      <div className="small" style={{ marginTop: 6, opacity: 0.75 }}>
                        {tools.map((t) => `${t.tool}${t.ok ? "" : " (gagal)"}`).join(", ")}
                        {actions.length > 0 && ` · tombol: ${actions.map((a) => a.label).join(", ")}`}
                      </div>
                    )}
                  </div>
                );
              })}
            </div>
          </details>
        );
      })}
    </main>
  );
}
```
